# WezTerm

Configuration for [WezTerm](https://wezfurlong.org/wezterm/) terminal emulator, symlinked via GNU Stow (`wezterm/dot-config/wezterm/wezterm.lua` -> `~/.config/wezterm/wezterm.lua`).

## Mouse Bindings

* **`CMD + Left Click`**: Intercepts mouse clicks at the terminal level and opens the URL or OSC 8 hyperlink under the cursor in your default browser, even inside mouse-reporting full-screen TUI applications (e.g., Neovim, AGY, lazygit).
